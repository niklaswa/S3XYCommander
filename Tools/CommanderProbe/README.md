# Commander Probe

A Mac app that connects straight to the S3XY Commander and shows and logs everything it sends,
so the protocol can be explored in the car without building an iPhone app each time.

```sh
./run.sh          # builds on first use, then starts the app; it connects by itself
./build.sh        # after changes to the probe or the library
```

- **One connection only.** The Commander takes a single client: switch off Bluetooth on the
  iPhone, or close Monav and the S3XY app, before starting the probe.
- **Pairing.** The first time, the Commander does not know the Mac: the app asks for a double
  press on the right scroll wheel. The Mac keeps its ID (`top.niklas.commanderprobe` defaults),
  so this happens once.
- **Notes.** Type what you just did ("route to Cologne started in the Tesla") and press
  *Markieren*: the line lands in the log between the pushes, so they can be matched up later.

## What it does

- Subscribes to all vehicle data and to the steering-wheel events, and asks the Commander for its
  Tesla API status (`ReqGetApiStatus`: whether it is paired with the car as a key and has an
  infotainment session — navigation and media fields depend on that).
- Decodes every push with the field names and enums from the firmware's proto descriptors
  (`Schema.swift`, generated by `gen-schema.py`); fields the schema does not know show up as
  `unbekannt_<n>`, pushes other than vehicle data under *Andere Pushes*.
- *Abfragen* sends the read-only `ReqGet…` requests (car config, settings, Commander info …) and
  lists the decoded answers. Nothing that changes the Commander or the car is offered.
- *Abonnieren* re-subscribes to all fields or only some, to see whether the Commander sends a field
  only when it is asked for.

## Logs

`logs/session-<time>.jsonl`: one line per push (`hex` raw, `fields` decoded), per answer, per note.
`logs/latest-state.json`: every field with its value, change count and last values, rewritten
every 10 seconds and on *Trennen*.

## Schema

```sh
python3 gen-schema.py ~/Downloads/s3xy-commander-ble-analysis/all_protos.txt
```

The probe uses two diagnostic hooks of the library: `S3XYCommanderClient.onRawPush` and
`sendRawCommand(_:)`.
